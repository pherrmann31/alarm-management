# Alarm Management v1.0.0b1 – Gruppen und automatische Aufnahme

Erster Testrelease der v1.0-Entwicklung. Neue Rauchmelder können automatisch in Standard aufgenommen und über eine gemeinsame Regel alarmiert werden. Manuelle Raumzuordnungen bleiben erhalten. Ausgabe-/Benachrichtigungsgruppen, native Tasterereignisse, Regelprioritäten, gestörte Eingänge und eine Verteilungsvorschau ergänzen die bestehenden Funktionen.

234 Offline-Tests bestanden. Live-Prüfung in Home Assistant und an realen Geräten steht aus. Vor dem Update vollständiges Backup erstellen. README mit Einrichtung, Grenzen und ausstehenden Punkten beachten.

Tag: `v1.0.0b1`. Auf GitHub als Pre-release markieren. Nicht als fertige v1.0.0 veröffentlichen.
