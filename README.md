# Eigenes Integrationssymbol

Kopiere deine PNG-Dateien in diesen Ordner auf Home Assistant:

`/config/custom_components/alarm_management/brand/`

| Datei | Abmessungen |
| --- | --- |
| icon.png | 256 × 256 Pixel |
| icon@2x.png | 512 × 512 Pixel |
| dark_icon.png (optional) | 256 × 256 Pixel |
| dark_icon@2x.png (optional) | 512 × 512 Pixel |

Quadratisch, möglichst transparent, ohne unnötigen Rand. Dunkle Varianten sind optional.
Ein quadratisches Logo benötigt keine zusätzliche logo.png. Eigene PNGs sind in diesem
Paket noch nicht enthalten. Nach dem Kopieren HA neu starten und die Browseransicht mit
Strg+F5 aktualisieren. Bei späteren Updates eigene Bilder sichern und wieder mitnehmen.

[Offizielle Vorgaben](https://contributors.home-assistant.io/core/integrations/brands/)
